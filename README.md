## Intro

This project was carried out during a 6 weeks internship. The aim was to develop a tool which would convert test result log files from the 
GERT testing system to a standard XML file that would be accepted within the UTW database, fulfilling the conditions of an XSD file. 

## Command

To run coverage command is :
```sh
dotnet build GertToUTWEngine.slnx -t:Coverage
```

To execute: 
app.exe file.log directory or if you want to give a lot number app.exe file.log directory --lot 123456
